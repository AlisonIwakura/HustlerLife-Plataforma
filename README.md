# 🚀 HustlerLife Platform

Plataforma web moderna construída com **Next.js + Node.js**, preparada para **produção**, com **PM2**, **Nginx (proxy reverso)** e **HTTPS via Let’s Encrypt**.

> 🔐 Ambiente seguro  
> ⚡ Performance otimizada  
> ♻️ Processo persistente  
> 🌍 Deploy em VPS Linux  

---

## 🌐 Produção

🔗 **Live:**  
👉 https://app.hustlerlife.store

---

## 🧠 Stack Tecnológica

| Camada | Tecnologia |
|------|-----------|
Frontend | Next.js (App Router)
Backend | Node.js
Process Manager | PM2
Proxy / Gateway | Nginx
SSL | Let’s Encrypt (Certbot)
Banco de Dados | MySQL
Infra | VPS Linux (Hostinger)
Versionamento | Git / GitHub
